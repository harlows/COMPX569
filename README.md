# Blogging Web Application
A full-stack blogging platform built as part of postgraduate study in COMPX569 (Programming with Web Technology). The project demonstrates core web development concepts including authentication, database design, and dynamic user interactions.
Overview
This application allows users to:

- Create accounts and manage their profiles
- Create, edit, and delete blog articles
- Upload images for articles
- Like and comment on posts (with nested replies)
- Browse and sort content dynamically without page reloads

The project was designed and implemented from scratch, focusing on clean architecture, usability, and maintainable code.

## Tech Stack

- Backend: Node.js, Express
- Database: MariaDB
- Frontend: HTML, CSS, JavaScript
- Other: Handlebars templating, RESTful routing

## Key Features

- Secure authentication (hashed passwords)
- Real-time validation (e.g. username availability)
- WYSIWYG-style content editing
- Nested comments (up to two levels)
- Dynamic sorting and interaction using JavaScript
- Image upload and management

## Development Approach

- Modular architecture (routes, DAOs, views)
- Emphasis on code readability and maintainability
- Iterative development with version control
- Designed for usability and responsive layout
